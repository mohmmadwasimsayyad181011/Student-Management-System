# Student Record and Academic Management System

**Student PRN:** `2126UMLM1123`  
**Language:** Python 3  
**Project type:** Command-line application

## Objective
Build a Student Record and Academic Management System demonstrating Python strings, lists, tuples, sets, and dictionaries. The program supports adding, searching, updating, deleting, displaying, and reporting student information.

## Requirements
- Python 3.9 or newer
- No third-party Python packages are required

## Run the project
1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run `python main.py` (on some systems use `python3 main.py`).
4. Select an option from the menu.
5. Option 11 loads sample records for demonstration. These are fictional sample records.

## Project contents
- `main.py` — integrated menu-driven application
- `programs/strings.py` — string method exercises
- `programs/lists.py` — list method exercises
- `programs/tuples.py` — tuple exercises
- `programs/sets.py` — set operations
- `programs/dictionaries.py` — dictionary operations
- `documentation/Assignment_Report.docx` — report with analysis, algorithms, pseudocode, flowchart descriptions, and test plan
- `documentation/Algorithms_Flowcharts_Pseudocode.md` — editable algorithms, pseudocode, and Mermaid flowcharts
- `documentation/TESTING.md` — test cases and expected results
- `screenshots/` — add your own screenshots of the program running

## Data structures used
- Strings: student names, departments, email addresses
- Lists: student catalogue, subjects, marks, attendance-related values
- Tuples: date-of-birth components and fixed identifiers in tuple exercise
- Sets: unique club names, departments, and subjects
- Dictionaries: labelled fields in each student profile

## Current limitations
The records are stored in memory and will reset when the program exits. This version does not use a database or file persistence. For a future extension, save and load records using JSON or SQLite.
